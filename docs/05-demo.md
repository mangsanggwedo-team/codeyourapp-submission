## 여정 시뮬레이션 (가장 먼저 볼 것)
[sim/journey/index.html](../sim/journey/index.html)을 브라우저로 연다(설치 없음). 지하주차장 단면도, Pleos 센터 디스플레이, 6단계 레버 타임라인, 베이지안 "마칠 준비" 확률, 차량 신호 로그가 한 화면에 재생된다.

| 조작 | 하는 일 |
|---|---|
| 시나리오 A · B · C | 귀가 직전 기도 15분 / 점심 조용히 머물기 8분 / 전화·문 열림·기어 이탈 |
| 5× · 20× · 60× | 재생 배속 |
| 신호 넣기 (화면 깨움, 등받이 세움, 다시 기댐, 벨트 맴) | 우도비로 확률을 바로 갱신해 마침 모델이 어떻게 반응하는지 본다 |
| 타임라인 클릭, ← → | 시점 이동, 단계 이동 |
| URL `?s=A&t=880&paused=1` | 특정 장면 고정(캡처용) |

데이터: [scenarios.json](../sim/journey/scenarios.json)은 [여정 사양](journey/여정_초정밀.md)에서 생성했고, 확률 `session.p`는 [EndingPolicy.kt](../core/src/main/kotlin/com/mangsang/app/core/EndingPolicy.kt)와 같은 식으로 계산했다.

## 에뮬레이터 시나리오
Virtual Console로 차량 상태를 바꾸며 확인한다. 3분.
| # | Virtual Console 조작 | 기대 결과 | 상태 | 영상 |
|---|---|---|---|---|
| 1 | 기어 D → P, 차속 0 | "잠시 이곳에 머무시겠어요?" 제안 | 웹 시뮬 (앱 화면 구현 중) | (0:00) |
| 2 | 15분 선택 | 잠금·창문·등받이·앰비언트·공조 변경 | 레버 set은 Virtual Console에서 실측됨, 흐름은 웹 시뮬 | |
| 3 | (아무것도 안 함) | 마칠 준비 확률이 올라 빛·소리·한 문장으로 닫힘 | 웹 시뮬 + `:core` 테스트 | |
| 4 | 머묾 중 기어 P → D | 즉시 모든 레버 복원 | 웹 시뮬 (복원 set은 실측) | |

상태 뜻: **Virtual Console** = 에뮬레이터에서 SDK로 실제 동작 · **웹 시뮬** = 시뮬레이터에서만 · **미구현** = 계획. 부풀리지 않는다.

## Non-Negotiable Principles

| ID | 원칙 | 뜻 | 무엇이 지키나 | 이러면 거절 |
|---|---|---|---|---|
| P1 | 서 있을 때만 | 기어 P, 차속 0, 운전석 착좌가 모두 확인될 때만 차량 명령을 낸다. 하나라도 모르면 금지 | SafetyGuard, MomentDetector 단위 테스트 | 값을 읽지 못했는데 명령이 나간다. P가 아닌 상태에서 세션이 이어진다 |
| P2 | 들어오기 전으로 되돌린다 | 레버를 만지기 전에 스냅샷을 남기고, 끝나거나 중단되면 그 값으로 복원한다. 읽지 못한 레버는 만지지 않는다 | VehicleGateway의 스냅샷과 복원, 에뮬레이터 전후 비교 | 스냅샷 없이 set을 호출한다. 세션 뒤 값이 시작 전과 다르다 |
| P3 | 기도는 차 밖으로 나가지 않는다 | 마이크, 서버, 네트워크 전송이 없다. 기도 내용은 받지도 않는다. 세션 기록과 팩 사용 이력은 기기 안에만 둔다. 바깥 음성 인식 서비스도 쓰지 않는다 | 매니페스트 권한 목록, 코드 검토 | 네트워크 또는 마이크 권한이 선언된다. 세션 단위 기록이 기기를 떠난다 |
| P4 | 끝을 묻지 않는다 | 끝은 마침 확률로 알아채고 빛, 소리, 한 문장 순서로 조금씩 닫는다. 마침 문장은 세션당 한 번 | EndingPolicy와 테스트 | "마치겠습니까?" 같은 확인 창이 뜬다. 정해진 시각에 소리로 끝을 선언한다 |
| P5 | 일찍 끊는 실수가 더 비싸다 | 기도 중인 사람을 깨우는 비용을 늦게 닫는 비용보다 크게 둔다. 되돌리기 쉬운 것부터 한다 | EndingCosts의 비대칭 문턱(0.50, 0.70, 0.85) | 문턱이 대칭으로 바뀐다. 초반 신호만으로 세션이 끝난다 |
| P6 | 손은 언제나 이긴다 | 묻지 않고 끝나고, 먼저 멈추고 싶을 때만 마치기 한 번. 조용한 마치기는 항상 화면에 있고, 사용자의 수동 조작과 안전 사건은 모델보다 먼저다 | UI 규칙, 안전 사건 표 | 끝내기 전에 묻거나, 마치기가 숨겨진다. 사용자가 바꾼 레버를 앱이 다시 덮어쓴다 |
| P7 | 차가 먼저 묻되 조르지 않는다 | 주차 순간에 한 번 제안하고, 같은 장소에서 두 번 거절하면 다시 묻지 않는다. 알림으로 부르지 않는다. 사용자가 직접 정해 둔 기도 시간에 한 번 알리는 것만 예외다 [가정: PM 확인 대기, Q-PRD-005] | 제안 로직, 거절 이력 | 거절 뒤에도 같은 곳에서 계속 뜬다. 사용을 독촉하는 알림이 있다 |
| P8 | 안전과 마침은 팔지 않는다 | 안전, 복원, 마침, 기본 의례는 무료다. 구독은 깊이를 더할 뿐 닫힘과 열림의 질을 가르지 않는다. 기도 한 번의 처음부터 끝까지는 무료이고, 한 번 무료로 준 것은 유료로 옮기지 않는다(S39) | 기능 명세의 무료·유료 표 | 유료 전환 유도가 세션 중에 나온다. 무료 사용자의 안전 기능이 줄어든다 |
| P9 | 머묾을 늘리려 하지 않는다 | 사용 시간과 연속 일수를 목표로 삼지 않는다. 세션 상한 30분. 연속 기록 보상 없음 | 지표 정의, 디자인 검토 | 스트릭, 배지, "어제보다 더 오래" 같은 문구가 들어간다 |
| P10 | 문구는 감수를 거친다 | 종교 문구는 감수 없이 내지 않는다. 룸19는 공간과 시간을 지키고 기도의 내용은 사용자의 것이다 | 팩 제작 절차, 감수 기록 | 감수 기록 없는 문구가 팩에 들어간다. 앱이 기도 내용을 만들어 준다 |
| P11 | 효능을 약속하지 않는다 | 치료, 스트레스 감소 수치, 신앙 성장 같은 결과를 약속하지 않는다. 근거가 말한 만큼만 말한다 | 문구 검토 | "불안이 줄어듭니다" 같은 단정이 있다 |
| P12 | 본 숫자만 쓴다 | 숫자는 원문확인 등급만. 우리가 정한 값은 [가정]과 식을 붙인다. 미정인 파트너를 확정처럼 쓰지 않는다 | `00_source-log.md`, 제출 전 점검 | 출처 번호 없는 숫자가 있다. 쓰면 안 되는 숫자가 들어간다 |
| P13 | 첫 타깃은 하나 | 지금은 매일 기도하는 한국 개신교 성인 운전자만 본다. 다른 팩과 무교 모드는 확장 계획에 둔다 | PRD 범위, `02_cps.md` Non-Solutions | 첫 출시 범위에 두 번째 팩이 들어온다 |

## Tradeoffs

| 맞바꿈 | 택한 쪽 | 이유 | 예외 |
|---|---|---|---|
| 무전송 대 집단 학습 | 무전송 | 기도는 가장 사적인 행위이고, 모으지 않는 것이 신뢰이자 방어력 | 참여자가 따로 동의한 파일럿의 요약값 |
| 무전송 대 사용 집계 | 무전송. 집계는 플랫폼 통계에 기댐 | MAU를 재려고 원칙을 깨지 않는다 | 동의 기반 익명 실행 횟수(OQ-03) |
| 정확한 끝 대 방해 없는 끝 | 방해 없는 끝 | 1~2분 더 앉아 있는 비용이 깨우는 비용보다 작다 | 세션 상한 30분, 안전 사건 |
| 깊은 이완 대 출발 안전 | 출발 안전 | 등받이는 시작할 때 뒤로 조금만 기울이고 눕히지는 않는다. 돌아옴에서 운전 자세로 되돌린 뒤에야 출발 준비를 보인다. 끝은 밝고 시원하게 | 없음 |
| 넓은 타깃 대 정확한 타깃 | 정확한 타깃 | 첫 팩의 진정성이 확장의 근거가 된다 | 사업성 단계의 "조용히 머물기" |
| 구독 수익 대 온전한 무료 | 온전한 무료 | 1순위 수익이 라이선스이므로 무료판이 곧 납품물 | 없음 |
| 묻기 대 추천 | 추천 | 고르게 하면 매일의 결심이 된다. 길이와 한 줄을 시간대와 지난 세션으로 미리 채운다 | 한 줄을 눌러 길이를 바꿀 수 있다 |
| 혼자 대 함께 | 혼자가 기본, 함께는 같은 흐름 | 동의하지 않은 사람의 자리와 몸은 바꾸지 않는다. 함께일 때는 좌석을 움직이지 않는다 | 빛과 잠금은 실내가 하나라 함께 바뀐다 |
| 끝을 확인받기 대 놓아주기 | 놓아주기 | 끝난 뒤의 버튼은 기도 뒤에 남는 과제다. 내리는 것과 출발하는 것이 대답이다 | [조금 더 머물기] 하나 |
| 자동 제안 대 조용함 | 조용함 | 조르는 차는 룸19가 아니다 | 사용자가 직접 켠 정기 제안 |

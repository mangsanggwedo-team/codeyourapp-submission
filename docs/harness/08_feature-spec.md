## F-01 주차 관문 (A)
- 목적: 주행 중에는 앱이 아무것도 하지 않게 한다.
- 계기: 기어, 차속, 착좌, 문 신호의 변화.
- 입력: 기어, 차속(0.5 m/s 초과면 움직임), 운전석 착좌, 운전석 문.
- 동작: `MomentDetector`가 주차로 판정하고 착좌와 문 닫힘이 참이면 6초 뒤 F-02를 부른다.
- 오류 상태: 신호가 하나라도 null이면 주행으로 본다. 후진은 주행과 같다.
- 수용 기준
  1. 기어 D, 차속 0에서 6초가 지나도 카드가 뜨지 않는다.
  2. 기어 P, 차속 0, 착좌, 문 닫힘에서 6초 뒤 카드가 뜬다.
  3. 기어 구독을 끊은 상태에서는 카드가 뜨지 않는다.
  4. `MomentDetectorTest` 7개가 통과한다 (지금 통과).
- 주행 없이 탄 경우: 일과 중 기도 시간에 세워 둔 차에 타도 판정 조건은 같다. 전원을 켠 직후 기어, 착좌, 문 신호가 언제 들어오는지는 실차에서 재지 못했다 [모름]. 신호가 오기 전에는 위 오류 상태대로 아무것도 하지 않는다.

## F-02 제안 카드 (A, B)
- 목적: 차가 먼저 조용히 묻는다. 시작은 사용자가 한다.
- 화면: 반쪽 카드. "잠시 머물다 갈까요", 지난번 값 "기도 · 15분", 버튼 [머물기] [오늘은 그냥 갈게요].
- 수용 기준
  1. 카드가 뜰 때 소리가 나지 않는다.
  2. 10초 동안 누르지 않으면 카드가 접히고 세션은 시작되지 않는다.
  3. [머물기]를 누른 뒤에만 차량 값이 바뀐다.
  4. (B) 알림을 눌러 앱이 열리면 같은 카드가 보인다.

## F-03 레버 저장 (A)
- 목적: 되돌릴 수 있는 것만 바꾼다.
- 동작: 레버마다 capability 확인, get, 디스크 기록 순서. 운전석(`ROW_1_LEFT`가 든 구역)만 고른다.
- 오류 상태: get이 실패한 레버는 "바꾸지 않음"으로 표시한다.
- 수용 기준
  1. 로그에서 `SnapshotSaved`가 첫 `LeverSet`보다 앞에 찍힌다.
  2. get 실패를 넣은 레버에는 `LeverSet`이 한 번도 찍히지 않는다.
  3. 저장 직후 앱을 강제 종료하고 다시 열면 저장 파일이 남아 있다.

## F-04 문턱 (A)
- 목적: 차를 닫힌 자리로 바꾼다.
- 출력 (밤 기준, 낮은 괄호)

| 레버 | 값 | 시간 | 확인 상태 |
|---|---|---|---|
| 앰비언트 | `#FFB15C` 20% (25%) | 8초 | set [실측], 값은 가설 |
| 풍량 | 한 단씩 낮춰 1까지 | 5초에 걸쳐 | [실측] |
| 창문 | 닫지 않는다. 열려 있으면 차 상태 줄에 "창문 열림"이라고 사실만 적는다 | | set은 [실측]으로 되지만 끼임 위험 때문에 MLP에서 뺐다 |
| 도어 잠금 | 이미 잠겼으면 다시 잠그지 않는다 | 즉시 | [실측] P단 |
| 등받이 | 뒤로 조금 (짧게 이동 뒤 정지. 이동 시간은 [가정], 눕히지 않는다. 뒷좌석에 사람이 있으면 움직이지 않는다) | | [실측] P단. 이동 시간은 실차에서 재야 한다 |
| 열선 | MLP에서는 바꾸지 않는다 | | [실측]. 계절 판단이 [가정]이라 뒤로 미뤘다 |
| 내외기 | 내기 순환이면 10분마다 외기로 | 머묾 동안 | set [실측] |

- 문장과 종의 순서는 F-18이 정한다(준비, 고요, 종, 첫 문장 "문을 닫았어요. 숨을 한 번 고를게요.").
- 수용 기준
  1. [머물기] 뒤 10초 안에 Virtual Console의 앰비언트가 20%, `#FFB15C`로 바뀐다.
  2. 풍량 값이 표와 같이 바뀌고 창문 값은 바뀌지 않는다.
  3. set이 50001로 거부된 레버가 있어도 숨 단계로 넘어간다.
  4. 조수석과 뒷좌석 구역의 값은 바뀌지 않는다.

## F-05 숨 (A, B)
- 목적: 몸을 먼저 내려놓는다.
- 동작: 들숨 4초, 날숨 6초. 낭독은 첫 한 번만, 그 뒤는 화면의 원과 구절 두 토막(F-23).
- 건너뛰기 (팀원 초기 설계에서 받음): 숨 화면을 한 번 두드리면 바로 머묾으로 간다. 두 번 이어 건너뛴 사람은 다음부터 숨이 한 번(10초)으로 줄고, 설정에서 되돌린다 [가정]. 이 두드림은 마침 신호로 세지 않는다.
- 빛 (A): 들숨 `#FFB15C` 20%, 날숨 `#FF9A3C` 15%. 위로 튀지 않고 아래로 내려앉는다. 마지막 날숨이 곧 머묾의 빛이다.
- (B): 화면의 원과 약한 진동 [가정].
- 수용 기준
  1. 원이 4초 동안 커지고 6초 동안 작아진다.
  2. "들이쉬고", "내쉬고" 낭독은 첫 한 번만 들린다.
  3. (A) 숨 단계 동안 앰비언트 밝기가 20%를 넘지 않는다.
  4. (A) 숨이 끝날 때 앰비언트가 15%이고, 머묾으로 넘어갈 때 조명 set이 추가로 나가지 않는다.

## F-06 머묾 (A, B)
- 목적: 아무것도 바뀌지 않는 시간을 지킨다.
- 동작: 낭독 1회 뒤 화면을 거의 검게 한다. 작은 "마치기"만 낮은 밝기로 남는다. 이것이 자유 기도이고 기본이다. 읽을 것은 사용자가 두드려 열 때만 나온다(F-24).
- 빛 (A): `#FF9A3C` 15% (낮 20%) 고정. 깜빡이거나 낭독에 맞춰 밝아지지 않는다.
- 수용 기준
  1. 낭독이 끝나고 20초 안에 화면이 검은 바탕이 된다.
  2. 머묾 동안 마침 단계가 STAY인 한 조명 set이 나가지 않는다.
  3. 화면에 숫자 시계나 남은 시간이 보이지 않는다 (복귀 시각을 직접 정한 사용자는 예외).
  4. 관문 신호(기어, 차속, 문, 착좌)를 1초마다 확인한 로그가 남는다.

## F-07 마침 (A, B)
- 목적: 끝을 묻지 않고 알아채서 닫는다.
- 판단: `EndingPolicy`. 시간이 지나면 로그정규 해저드로, 신호가 오면 우도비로 p를 갱신한다.

| 단계 | 조건 [가정] | 출력 | 되돌릴 수 있나 |
|---|---|---|---|
| 빛 올림 | p > 0.50 | 앰비언트 +2%/분 (A), 화면 조금 밝게 (B) | 쉽다 |
| 소리 물림 | p > 0.70 | 배경음을 5초마다 1dB씩 | 중간 |
| 마침 문장 | p > 0.85, 마지막 신호 뒤 4초 조용함 | "이제 천천히 돌아올게요." 한 번 | 어렵다 |

- 규칙: 내려올 때는 문턱에서 0.10을 뺀 값 아래여야 한다. 머묾 쪽 신호(우도비 1 미만)가 오면 올린 빛과 줄인 소리를 20초에 걸쳐 되돌린다. 마침 문장은 세션당 한 번. "마치기"를 누르면 p = 1. 30분이면 p = 1.
- 앱이 set한 직후의 값 변화는 신호로 치지 않는다 (공조 3초, 등받이 2초 [가정]).
- 신호 (A): 화면 터치는 확실. 벨트, 브레이크, 방향지시등, 전조등, 공조와 창문 수동 조작은 [문서]. 등받이는 에뮬레이터 조회가 0 고정이라 실측에서 값이 안 변하면 뺀다.
- 신호 (B): 화면 터치, 들어올림, 잠금 해제, 차량 블루투스 재연결 [가정].
- 수용 기준
  1. 기본 맥락(운전 30분, 낮)에서 신호가 없을 때 마침 문장은 "의향 길이에서 돌아옴 90초를 뺀 시각"보다 일찍 나오지 않는다. 15분 의향이면 13분 30초 뒤, 설계 예시로는 약 16분대다 (`withoutSignalsClosingWordsComeNearIntendedLength`).
  2. 세션 2분째에 준비 쪽 신호를 여러 번 넣어도 단계가 STAY다 (`earlySignalsCannotEndSession`).
  3. 머묾 쪽 신호 뒤 20초에 걸쳐 앰비언트가 단계 시작 값으로 돌아온다.
  4. 한 세션에서 마침 문장 낭독 로그가 두 번 찍히지 않는다.
  5. 마침까지 화면에 질문 팝업이 한 번도 뜨지 않는다.
  6. "마치기"를 누르면 1초 안에 돌아옴으로 넘어간다.
  7. 30분에 반드시 돌아옴으로 넘어간다.

## F-08 돌아옴과 복원 (A)
- 목적: 차와 사람을 원래대로 돌려놓는다.
- 순서: 마침 문장, 시작과 같은 종, 빛, 좌석, 바람.
- 빛: `#FFC489` 30%까지 25초. 사용자의 저장값이 30%보다 낮으면 저장값까지만 올린다. 세션이 닫힐 때(닫기, 시동 꺼짐) 저장한 색과 밝기로 1.5초에 걸쳐 되돌린다. 차가운 흰색으로 번쩍이지 않는다.
- 화면: 검은 바탕에 "끝났어요." "좌석과 공조를 원래대로 돌렸어요." 닫기 버튼은 없다. 끝난 뒤의 닫힘은 F-21이 정한다.
- 수용 기준
  1. 돌아옴 동안 앰비언트 밝기가 저장값과 30% 중 작은 값을 넘지 않는다.
  2. 세션이 닫힌 뒤 Virtual Console의 조명, 풍량, 잠금 값이 저장값과 같다. MLP가 바꾸지 않는 온도, 열선, 창문 값은 세션 내내 그대로다.
  3. 등받이는 뒤로 움직인 시간만큼 앞으로(운전 자세 쪽) 움직인 로그가 있다.
  4. 좌석이 움직이는 동안 문 열림을 넣으면 이동이 멈춘다.
  5. 끝 화면이 흰 바탕이 아니다.

## F-09 안전 이탈 (A, B)
- 목적: 운전이 시작되면 앱은 물러난다.
- 계기 (A): 기어가 P가 아님, 차속 발생, 관문 신호 끊김. (B): F-15.
- 동작: 소리 즉시 0. 빛은 저장한 설정으로 1.5초. 풍량, 열선은 바로 저장값. 화면은 "원래대로 돌렸어요." 한 줄 뒤 비움. 버튼 없음. 개인화에는 넣지 않는다.
- 수용 기준
  1. 기어를 R 또는 D로 바꾼 뒤 1초 안에 소리가 멎는다 [가정: 1초].
  2. 2초 안에 앰비언트가 저장값이다.
  3. 등받이 set이 거부되면 `RestoreDeferred`가 찍힌다.
  4. 이탈 뒤 화면에 버튼이나 질문이 없다.
  5. 이 세션 뒤 `EndingPrior` 값이 바뀌지 않는다.

## F-10 멈춤 두 가지 (A)
- 이전의 일시정지를 둘로 나눈다. **방을 지킨 멈춤**은 전화, 창문을 손으로 내림(누가 두드림), 화면을 길게 누름이다. 소리만 끄고 잠금, 바람, 등받이는 그대로 둔다. 빛은 22%로 3초에 올린다 [가정]. **문이 열린 멈춤**은 운전석 문 열림과 자리 비움이다. 빛을 원래 밝기로 올리고 좌석은 움직이지 않는다. 앱은 마이크가 없어 두드리는 소리를 듣지 못한다. 사용자의 손(창문, 화면)으로만 안다.
- 멈춤에서 끝낼 때: 마치기를 누르면 마침 문장 없이 종 한 번과 복원으로 간다. 멈춘 시간은 머문 시간에 넣지 않는다.
- 이어 갈 때(2관문에서 고침): 처음부터 다시 하지 않는다. 문턱, 들어섬 신호, 숨, 낭독을 되풀이하지 않고 멈춘 자리(머묾)에서 잇는다. 아래 표의 "이어서 머물까요?" [이어서 머물기] [마치기] 두 버튼은 **[이어서 머물기] 하나**로 바꾼다. 20초 [가정] 안에 누르지 않으면 말없이 되돌리고 닫는다. 조르는 문구, 다시 묻기, 다음 제안에서 "지난번에 멈췄어요" 같은 말은 없다. 그렇게 닫힌 세션은 개인 값에 넣지 않는다.
- 창: 방을 지킨 멈춤은 3분 안에 끝나면 묻지 않고 잇고, 3분을 넘겨 끝나면 위의 한 가지를 보인다. 10분 [가정]을 넘기면 통화가 이어지는 중이어도 말없이 되돌린다. 문이 열린 멈춤은 120초 안에 돌아와 앉으면 한 가지를 보이고, 넘기면 말없이 되돌린다.
- 계기와 동작

| 계기 | 동작 | 이어 가기 |
|---|---|---|
| 오디오 포커스 상실 (전화) | 소리 0, 모델 시계 멈춤, "잠시 멈춰 둘게요." | 포커스가 돌아오면 "이어서 머물러요." 숨 안내는 다시 하지 않는다. 3분 넘으면 "이어서 머물까요?" |
| 창문을 손으로 내림, 화면을 길게 누름 | 소리를 물리고 빛 22%로 3초, 시계 멈춤, "잠시 멈춰 둘게요." 끝내자고 하지 않는다 | 창문이 닫히거나 화면을 두드리면 "이어서 머물러요." 빛을 머묾 값으로 8초 |
| 운전석 문 열림 | 소리 0, 빛은 저장값으로 1.5초, 좌석 이동 정지, 시계 멈춤 | 문 닫힘과 착좌 뒤 "이어서 머물까요?" [이어서 머물기] [마치기] |
| 착좌 해제 | 문 열림과 같음 | 120초 넘게 비우면 복원하고 끝낸다 |

- 수용 기준
  1. 일시정지 동안 p 값이 변하지 않는다.
  2. 문 열림 뒤 2초 안에 앰비언트가 저장값이다.
  3. 121초 뒤에는 카드 없이 세션이 끝나 있고 레버가 저장값이다.
  4. 포커스 신호가 오지 않는 환경에서는 화면을 한 번 두드리면 일시정지된다 (대체 경로).

## F-17 기도 시간 알림 (B, A는 탑승 뒤 제안만) [가정]
- 목적: 일하다 기도 시간이 되면 차로 가서 기도하고 돌아오는 장면을 돕는다 (DEC-016, 06 S7).
- 설정: 사용자가 요일과 시각, 팩, 길이를 직접 정한다(`PrayerSchedule`). 기본은 꺼짐이고 하루 3개까지 [가정].
- 동작 (B): 정한 시각에 휴대폰 알림 한 번 "잠시 머물다 갈까요". 소리 없음. 잠금 화면에서 신앙이 드러나지 않게 F-14와 같은 문구를 쓴다. 누르면 F-02. 누르지 않아도 다시 알리지 않는다.
- 동작 (A): 차 안 앱은 차 밖에 있는 사람에게 알릴 수 없다. 정한 시각 앞뒤 30분 [가정] 안에 차에 타 F-01을 지나면 제안 카드에 그 시간의 팩과 길이를 채워 보여 준다.
- 한계: 앱은 시동을 걸거나 문을 열거나 미리 공조를 켜지 못한다. 휴대폰 OS가 알림을 몇 분 늦게 띄울 수 있다(절전 상태, 정확한 알람 권한) [가정: 팀 실측 없음]. Pleos판만 쓰는 사용자에게 휴대폰으로 알릴 경로가 있는지는 확인하지 못했다 [모름].
- 원칙과의 관계: 03 P7은 "알림으로 부르지 않는다"이다. 이 알림은 사용자가 스스로 정한 시각에만 가고 독촉이 아니므로 예외로 두었다. 예외 범위는 PM 확인 대기(Q-PRD-005).
- 수용 기준
  1. 기도 시간을 정하지 않으면 이 알림은 한 번도 오지 않는다.
  2. 정한 시각에 알림이 한 번 오고, 같은 시각에 대해 다시 오지 않는다.
  3. 알림 문구에 기도, 팩 이름, 종교를 알 수 있는 말이 없다.
  4. 알림 권한을 거절해도 차에 타서 직접 시작할 수 있다.
  5. 기록 지우기를 하면 정해 둔 기도 시간도 지워진다.

## F-18 들어섬 신호 (A, B는 화면과 종만) · 2관문 신규
- 목적: 설명 없이 "이제 안에 있다"를 알린다. 영화관에서 불이 꺼지고 로고 소리가 한 번 울리는 것과 같은 자리다.
- 순서와 시각 (머물기를 누른 때가 0초, 값은 [가정])

| 시각 | 일 | 이유 |
|---|---|---|
| 0 ~ 0.25초 | 버튼이 사라지고 화면이 어두워진다 | 눌렸다는 응답 |
| 0 ~ 0.6초 | 레버 저장 (F-03) | 저장 먼저 |
| 0.6 ~ 6초 | 문 잠금, 빛 내림, 바람 낮춤, 등받이 뒤로 조금 (F-04). 말 없음. 차 상태 줄에 낱말만 | 준비하는 동안 말을 걸면 따라가야 할 것처럼 느낀다 |
| 6 ~ 7초 | 고요. 모든 움직임과 소리가 멈춘다 | 신호는 정적 뒤에 올 때 신호가 된다 |
| 7초 | 종 한 번(여운 약 2초). 화면의 문턱선이 가운데로 모였다 가라앉는다(약 1.2초) | 귀와 눈에 같은 순간 하나 |
| 9초 | 첫 문장, 목소리와 글자: "문을 닫았어요. 숨을 한 번 고를게요." 그 아래에 구절 한 줄이 글자로만(F-23) | 차가 한 일을 확인해 주는 말. 신호 뒤에 와야 신호를 가리지 않는다 |
| 12초 | 숨 (F-05) | |

- 규칙
  - 신호는 하나다. 소리 하나와 빛의 움직임 하나. 매번 같고, 계절이나 날에 따라 바꾸지 않는다. 같아야 몸이 배운다.
  - 신호는 준비가 끝났을 때만 울린다. 바꾸기가 6초를 넘기면 신호도 늦춘다. 12초가 지나도 끝나지 않은 레버는 버리고 진행한다 [가정].
  - 같은 종이 돌아옴에서 한 번 더 울린다. 시작과 끝이 같은 소리로 묶인다(D8의 "시작과 같은 신호로 닫기").
  - 건너뛰는 버튼은 없다. 마치기는 0.25초부터 화면에 있다.
  - 뒷좌석에 사람이 있으면 종을 작게(-24dB), 문장은 글자만.
- 바꾼 문구: 이전 "문을 닫고, 숨을 한 번 고를게요."는 준비 전에 하는 말이었다. 준비가 끝난 뒤에 말하므로 "문을 닫았어요."로 고친다 [가정: 감수 전 초안. 여정 문서와 시안에는 아직 이전 문구가 있다].
- 수용 기준
  1. 종은 잠금과 빛과 바람의 set 콜백이 모두 돌아온 뒤에만 울린다(로그 시각 순서).
  2. 종 앞 1초 동안 앱이 내는 소리와 set 호출이 없다.
  3. 첫 문장은 종보다 뒤에 시작한다.
  4. 열 번 실행해 종과 문턱선의 움직임이 매번 같다.

## F-19 앉으면 추천 (A, B) · 2관문 신규
- 목적: 고르게 하지 않는다. 제안의 한 줄을 미리 채운다.

- 규칙

| 조건 | 한 줄 |
|---|---|

  3. 추천에 쓰는 값은 기기 밖으로 나가지 않는다(F-12).

## F-20 함께 머묾 (A) · 2관문 신규
- 목적: 배우자, 가족, 동료와 같이 기도하는 경우에도 같은 한 번의 누름으로 간다. 화면과 흐름은 혼자일 때와 같다.
- 달라지는 것

| 항목 | 혼자 | 옆자리에 사람 | 뒷좌석에 사람 |
|---|---|---|---|
| 제안 문구 | 잠시 머물다 갈까요 | 같이 머물다 갈까요 | 혼자와 같음 |
| 운전석 등받이 | 뒤로 조금 | 움직이지 않음 | 움직이지 않음 |
| 다른 자리의 좌석, 바람 | 해당 없음 | 건드리지 않음 | 건드리지 않음 |
| 빛, 잠금 | 바꿈 | 바꿈 (실내가 하나라 나눌 수 없다. 그래서 제안 문구로 먼저 알린다) | 바꿈 |
| 낭독과 목소리 | 켬 | 켬 | 끔, 글자만. 종은 작게 |
| 배경음 | 팩 기본 | 끔 | 끔 |
| 마치기 | 운전자 | 누구나 | 누구나 |
| 마침 신호 | 전부 | 운전석 쪽 신호와 화면 터치만 | 운전석 쪽 신호와 화면 터치만 |

- 누가 정하나: 시작은 운전석의 한 번 누름이다. 옆 사람은 같은 화면을 보고 있고 마치기를 누를 수 있다. 앱은 누가 기도하는지, 무슨 말을 하는지 알지 못하고 알려고 하지 않는다.
- 한계: 조수석과 뒷좌석 착좌 신호는 문서로만 확인했다 [문서]. 신호를 못 읽으면 혼자로 보되 등받이는 움직인다. 함께 기도하는 사용이 얼마나 되는지는 근거가 없다 [가정].
- 수용 기준
  1. 조수석 착좌가 참이면 등받이 set이 한 번도 나가지 않는다.
  2. 조수석과 뒷좌석 구역의 공조 값이 세션 전후로 같다.
  3. 뒷좌석 착좌가 참이면 낭독이 재생되지 않는다.

## F-21 건넴 (A, B는 한 줄과 버튼만) · 2관문 신규
- 목적: 끝난 뒤의 다음 걸음을 묻지 않고 받아 준다.
- 화면: "끝났어요." / 되돌린 값(실제로 바꾼 것만) / 때에 맞는 한 줄. 이전의 [닫기] 버튼은 없앤다 [가정: 시안에는 아직 있다]. 차례로 누르는 메뉴와 고르는 목록은 두지 않는다. 권하는 것은 많아야 하나([조금 더 머물기])이고, 끝이 일렀을 법할 때만 보인다(문장 직전 30초 안에 반대 신호가 있었거나 지난번에 이것을 쓴 경우 [가정]). 버튼이 없을 때도 화면을 길게 누르면 같은 일이 된다.
- 뜻을 짐작하는 재료: 시각과 요일, 운전을 마친 주차인지 운전 없이 탄 것인지, 세션 길이, 지난 건넴(내림, 출발), 지금 들어오는 신호(벨트, 브레이크, 기어). 위치는 읽지 않는다. 집 주차장과 회사 주차장을 가르는 것은 이 재료로 하는 짐작이다 [가정].
- 때에 맞는 한 줄

| 맥락 (시각과 지난 행동으로 판단) | 한 줄 | 차가 기다리는 행동 |
|---|---|---|
| 저녁 이후, 운전을 마친 뒤의 주차 | 천천히 올라가세요. | 문 열림, 시동 끔 |
| 낮, 운전 없이 탄 경우 또는 정한 기도 시간 | 12시 38분이에요. | 문 열림 |
| 아침, 또는 지난번 이 시간대에 끝나고 바로 출발한 사람 | 출발해도 좋아요. | 기어 이동 |
| 30분 상한으로 끝남 | 출발하기 전 2분만 더 앉아 있어요. | |
| 벨트를 매거나 브레이크를 밟거나 기어를 옮김 (곧 출발) | 말하지 않는다. 화면을 바로 치운다 | 이미 온 신호 |
| 일찍 마침(60초 안에 마치기, 또는 문턱·숨에서 마치기): 오늘은 마음이 아님 | 한 줄도 종도 없다. "끝났어요."도 띄우지 않고 되돌린 뒤 홈으로 | 없음. 개인 값에 넣지 않고 다음 제안에서 꺼내지 않는다 |
| 판단이 안 서면 | 한 줄 없음 | |

- 닫히는 길: 문 열림, 기어 이동, 시동 끔, 90초 무응답. 어느 것이든 빛을 원래 설정으로 돌리고 화면을 치운다. 기어가 옮겨져도 안전 이탈로 다루지 않는다. 등받이와 바람은 이미 돌아와 있기 때문이다.
- 깨끗하게 멈춘다: 어떤 소리도 뚝 끊지 않는다(가장 급한 안전 이탈도 0.3초에 걸쳐 물린다 [가정]). "정말 마칠까요" 같은 되묻기는 어디에도 없다. 마치기는 누르는 즉시 돌아옴이다.
- 조금 더 머물기: 5분. 문턱과 숨 없이 빛만 머묾 값으로 8초, 등받이는 움직이지 않는다. 끝은 문장 없이 종 한 번. 한 세션의 합은 30분을 넘지 않는다. 누른 사실을 요약에 남겨 다음 추천과 개인 값에 반영한다.
- 수용 기준
  1. 출발 준비 화면이 보일 때 등받이와 바람과 잠금이 이미 저장값이다.
  2. 문을 열면 2초 안에 앰비언트가 저장값이고 화면에 룸19가 없다.
  3. 아무것도 하지 않으면 90초 뒤 같은 상태가 된다.
  4. 이 화면에 기록, 통계, 권유, 다음 추천이 없다.
  5. 조금 더 머물기 뒤의 끝에서 마침 문장이 다시 나오지 않는다.
  6. 이 화면에 동시에 보이는 버튼이 하나 이하다.
  7. 60초 안에 마치기를 누른 세션은 출발 준비 화면 없이 닫히고, 개인 값이 바뀌지 않는다.
  8. 앱 전체에 확인 창("마치겠습니까" 류)이 없다.

## F-22 목소리와 개입 (A, B) · 2관문 신규
- 규칙은 06 13.6절의 표가 정본이다. 말로 끼어들기는 MLP 밖이고 조건(기기 안 낱말 수준만, 녹음과 바깥 음성 인식 없음 [가정])은 같은 절에 적었다.
- 수용 기준
  1. 한 세션에서 낭독(TTS) 호출이 네 번 이하다.
  2. 매니페스트에 마이크 권한(`RECORD_AUDIO`)과 네트워크 권한이 없다.
  3. 낭독이 실패해도 같은 문장이 화면에 보이고 세션이 이어진다.
  4. 설정에서 목소리를 끄면 낭독 호출이 0번이다.
  5. 머묾 중 화면을 한 번 두드리면 5초 동안 마치기가 또렷해지고, 길게 누르면 방을 지킨 멈춤으로 간다.

## F-23 들어섬 구절과 숨의 구절 (A, B) · 2관문 보완
- 목적: "이제 안이다" 뒤에 "왜 여기 왔나"를 한 줄로 놓는다. 붙잡을 것 하나를 준다(D1 3절).
- 동작
  - 들어섬: 종(7초) 뒤 첫 문장(9초)이 뜰 때 그 아래에 작은 명조 글자로 구절 한 줄과 출처. 기본은 `네 룸19에 들어가 문을 닫고` / `마태복음 6:6`. 글자만이고 읽어 주지 않는다. F-18의 시각은 바뀌지 않는다.
  - 숨: 원 아래에 같은 구절을 두 토막으로. 들숨 4초에 `네 룸19에 들어가`, 날숨 6초에 `문을 닫고`. 첫 숨의 낭독("들이쉬고", "내쉬고")이 끝난 둘째 숨부터 보인다.
  - 머묾 진입의 구절 낭독(F-06)은 같은 절의 앞 문장이다. 한 구절이 눈, 숨, 귀로 세 번 온다.
  - 제안 한 줄이 "말씀 묵상"으로 채워진 세션은 들어섬 구절이 오늘의 말씀에서 고른 한 줄로 바뀐다 [가정].
- 규칙: 구절은 팩의 고정 데이터다. 절의 일부를 끊어 쓸 때는 본문과 글자가 같아야 하고 뜻이 달라지게 끊지 않는다(감수 항목). 이 장치를 "호흡 기도"라 부르지 않는다. 설정의 "숨에 말씀 보이기"로 끌 수 있다.
- 수용 기준
  1. 구절 한 줄은 종보다 뒤에 보이고, 이때 낭독 호출이 추가로 나가지 않는다.
  2. 숨의 두 토막이 원의 커짐과 작아짐에 맞춰 바뀐다(어긋남 0.3초 안 [가정]).
  3. 화면의 구절이 팩 본문의 부분 문자열과 글자까지 같다.
  4. 설정에서 끄면 숨 화면에 원만 보인다.

## F-24 머묾의 기도 방식 (A, B) · 2관문 보완
- 목적: 침묵을 기본으로 두고, 원하는 사람에게만 읽을 것을 준다.
- 여는 법: 머묾에서 화면을 한 번 두드리면 5초 깨어난다(F-22). 이때 아래에 낱말 셋 `말씀` `기도문` `기도 제목`이 흐리게 보인다. 누르지 않으면 사라지고 자유 기도가 이어진다. 세션 앞에 고르는 화면은 없다.
- 방식

| 방식 | 화면 | 넘어가는 법 | 낭독 |
|---|---|---|---|
| 자유 기도 (기본) | 거의 검다 (F-06) | 없음 | 들어갈 때 구절 한 번 |
| 기도문 | 한 편을 큰 글자로(내장: 주기도문, 마 6:9~13 본문 [가정]). 길면 두드려 다음 쪽 | 끝 쪽에서 두드리거나 60초 뒤 어두워짐 | 낭독 몫이 남았으면 한 번 |
| 오늘의 말씀 묵상 | 본문 2~6절과 맨 아래 `읽고, 머물고, 한 문장으로 기도합니다.` | 90초 뒤 또는 두드리면 한 줄만 흐리게 남고 어두워짐 | 낭독 몫이 남았으면 한 번 |
| 기도 제목 | 한 화면에 한 줄 | 두드리면 다음 줄. 마지막 줄 뒤 어두워짐 | 없음 |

- 오늘의 말씀: 앱에 든 구절 묶음(31개 [가정], 개역한글)에서 날짜로 하나. 네트워크를 쓰지 않는다. 해설과 적용 질문은 없다.
- 기도 제목: 주차 중 설정에서만 적는다(일곱 줄까지, 한 줄 30자 [가정]). 세션 중에는 적지 못한다. 조수석이나 뒷좌석 착좌가 참이면 `기도 제목` 낱말이 보이지 않는다. 응답 표시, 횟수, 알림이 없다.
- 제안 한 줄: 지난 세 세션 가운데 두 번 이상 말씀을 연 사람에게는 `말씀 묵상 15분`으로 채우고, 머묾에 들어갈 때 구절 낭독 대신 본문을 연다 [가정]. 먼저 내미는 것은 이 한 줄뿐이다.
- 마침 모델과의 관계: 읽을 것을 여는 두드림과 쪽 넘김은 마침 신호로 세지 않는다(F-07의 화면 터치 신호에서 뺀다). 읽을 것이 열려 있는 동안 빛 올림 단계에 들어가면 글자는 그대로 두고 빛만 오른다.
- 수용 기준
  1. 두드리지 않은 세션에는 구절, 기도문, 기도 제목이 머묾 화면에 한 번도 보이지 않는다.
  2. 한 세션의 낭독 호출 합이 네 번 이하다(F-22 기준 1과 같다).
  3. 옆자리 착좌가 참이면 기도 제목을 여는 길이 없다.
  4. 기록 지우기를 하면 기도 제목과 방식 기억이 지워진다.
  5. 읽을 것을 열고 닫는 터치가 마침 확률을 바꾸지 않는다(로그).
  6. 매니페스트에 네트워크 권한 없이 오늘의 말씀이 뜬다.

## F-25 독서등 (A) · 2관문 보완 [예정]
- 목적: 말씀을 읽을 때 손 위만 밝힌다. 종이 성경과 큐티 책을 펴는 사람도 쓴다.
- 동작: F-24에서 말씀이나 기도문을 열면 운전석 독서등을 2~3초에 걸쳐 켠다. 닫거나 화면이 어두워지면 2~3초에 걸쳐 끈다. 기도 제목에는 켜지 않는다.
- 규칙: 문턱의 저장(F-03)에 독서등 값을 넣고 끝에 되돌린다. 다른 자리의 등은 건드리지 않는다. 가장 낮은 단계로 켠다. 설정에서 끌 수 있다. 앱이 켠 직후의 빛 변화는 마침 신호로 세지 않는다.
- 상태: 실내등 제어를 에뮬레이터에서 재지 못했다 [문서]. 서서히 켜기를 지원하는지도 모른다 [모름]. 재기 전까지 화면 글자(검은 바탕, `#FFB15C` 계열, 낮은 밝기)만 쓴다.
- 수용 기준 (실측 뒤)
  1. 말씀을 연 뒤 3초 안에 독서등 값이 목표에 닿고, 닫은 뒤 3초 안에 저장값이다.
  2. 조수석과 뒷좌석 등의 값이 세션 전후로 같다.
  3. 안전 이탈 때 독서등은 빛과 같은 순서로 저장값이 된다.

## F-26 끝 1분 전 종과 소리 규칙 (A, B) · 2관문 보완
- 1분 전 종: 끝 시각을 사람이 정한 세션에서만 울린다.

| 세션 | 종 | 크기 |
|---|---|---|
| 돌아갈 시각을 정함 | 그 시각 1분 전 | 들어섬 종보다 12dB 작게 [가정] |
| 30분 상한 | 29분 | 같음 |
| 조금 더 머물기 5분 | 4분 | 같음 |
| 마침 모델이 알아채는 세션 | 없음. 빛 올림이 예고다 | |

- 소리 규칙
  - 종은 한 음원이고 한 세션에 세 번 이하다(들어섬, 1분 전, 돌아옴).
  - 낭독이 끝난 뒤 20초 안에는 앱이 소리를 내지 않는다.
  - 낮은 실내 소리는 팩 기본값이고 설정에서 끈다. 함께일 때는 끈다(F-20). 음악과 찬양은 내장하지 않는다.
  - 낭독은 보통 속도보다 조금 느리게(0.9배 [가정]), 문장 사이 1.5초. 뒷좌석에 사람이 있으면 낭독 없이 글자만, 종은 작게(F-18).
  - 방을 지킨 멈춤 동안에는 1분 전 종을 울리지 않고, 이어 간 뒤 남은 시간이 1분 아래면 생략한다.
- 수용 기준
  1. 마침 모델로 끝난 세션의 로그에 종이 두 번이다.
  2. 돌아갈 시각을 정한 세션은 그 시각 60초 전(±2초)에 종이 한 번 더 있다.
  3. 낭독 끝과 다음 소리 사이가 20초 이상이다.

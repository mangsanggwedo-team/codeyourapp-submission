- 모든 URL은 HTTP 200으로 열렸다. 예외 1건(whichcar 403). hyundainews.com 두 개는 열리지만 JS 렌더링 껍데기여서 본문을 못 읽는다. 같은 보도자료의 PRNewswire 전재본으로 대조했다.

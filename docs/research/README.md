# 리서치 근거

기획서와 PT에서 쓰는 숫자와 주장의 근거. 원문 리서치(종교·의례, 심리·생리, 시장·통계, 선례, 경험 설계 등 13개 도메인)는 팀 비공개 저장소에 있고, 여기에는 인용 가능한 것만 둔다.

| 파일 | 내용 |
|---|---|
| [인용카드.md](인용카드.md) | PT에서 "어디 조사예요?"에 바로 답하는 숫자. 원문 확인한 것만, 그리고 쓰면 안 되는 숫자 목록 |
| [참고문헌_APA.md](참고문헌_APA.md) | APA 7판 참고문헌 34건과 본문 인용 대조표 |
| [stats/](stats/) | 통계 인사이트 사이트(인터랙티브 그래프, 데이터셋 40개)와 할루시네이션 감사 결과 |

## 검증 방식 (2026-11-15)
1. 숫자마다 출처 URL을 기록하고 1차 출처(정부 통계, 국제기구, 기업 IR, 학술지, 조사기관 원문)를 우선한다.
2. 감사 에이전트가 각 URL을 직접 열어 행마다 원문 값과 대조했다(현대차 재무 22개, 사회 통계·메인 49건). 판정: 검증통과 / 수정필요 / 출처교체필요 / 사용금지.
3. 사라진 보도자료는 웹 아카이브 사본으로 원문을 확인했다(Halfords 2025).
4. 원문에 없는 숫자(예: Halfords "평균 13분")는 기획서와 PT에서 쓰지 않는다.

통계 사이트를 로컬에서 보려면 [stats/index.html](stats/index.html)을 브라우저로 연다(D3 CDN 필요). 데이터를 고치면 `python3 stats/build.py`.

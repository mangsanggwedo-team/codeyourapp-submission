## 1. 컨셉

**이름: 문틈의 빛**

**한 줄: 닫힌 문 아래로 빛 한 줄이 샌다. 화면에는 그 한 줄과 한 문장만 있다.**

룸19는 성소가 아니라 집 안의 평범한 방이고, 방을 방으로 만드는 것은 닫힌 문이다. 그래서 화면의 유일한 그림은 문턱에 걸린 빛 한 줄(이하 **문턱선**)이다. 문턱선은 여섯 단계 내내 같은 자리에 있고, 길이와 색과 밝기만 바뀐다. 차 안 앰비언트 빛과 같은 색을 쓰기 때문에 화면은 실내 빛의 일부처럼 보인다.

비슷한 차량 프로그램들은 화면을 오로라와 폭포 영상으로 채운다. 룸19는 화면을 비운다. 밤 차 안에서 가장 센 광원이 화면이기 때문이다(조명 v2, 가설).

**대담함은 한 군데만.** 문턱선 하나. 나머지는 여백, 글자, 헤어라인.

## 2. 단계별 감정 목표

| 단계 | 사용자가 느낄 것 | 느끼면 안 되는 것 | 문턱선 |
|---|---|---|---|
| 준비(도착 제안) | 물어봐 줬다. 거절해도 된다 | 또 알림이 왔다 | 색 없는 흰빛, 흐리게. 아직 방이 아니다 |
| 문턱 | 문이 닫혔다. 차가 대신 해 준다 | 뭔가 시작돼서 따라가야 한다 | 호박색 `#FFB15C`, 8초에 걸쳐 좁아진다 |
| 숨 | 숨이 길어졌다 | 숨을 채점받는다 | 원이 숨과 함께 커졌다 작아진다. 선은 그 아래 그대로 |
| 머묾 | 혼자다. 아무도 재촉하지 않는다 | 화면이 나를 본다. 시간이 간다 | 가장 짧고 가장 어둡다 `#FF9A3C`. 움직이지 않는다 |
| 돌아옴 | 알아채 줬다. 서두르지 않는다 | 끊겼다. 쫓겨난다 | 웜화이트 `#FFC489`, 25초에 걸쳐 넓어진다 |
| 출발 준비 | 다 원래대로다. 가도 된다 | 평가받는다. 뭔가 더 하라고 한다 | 화면 끝에서 끝까지. 문이 열렸다 |

## 3. 시각 언어

### 3.1 활자

| 역할 | 글꼴 | 쓰는 곳 | 크기 (2560x1440 실제 px) [가정] |
|---|---|---|---|
| 목소리 | Noto Serif KR 400 | 차가 하는 말, 말씀, 마침 문장. 한 화면에 한 줄 | 전체 112~152, 반쪽 96~108 |
| 정보 | Pretendard 500/600 | 버튼, 차 상태, 되돌린 값, 시각 | 본문 44~54, 최소 34 |
| 숫자 | Pretendard, tabular | 풍량, 온도, 시각 | 정보와 같음 |

- 목소리는 낭독되는 문장에만 쓴다. 버튼과 설정에는 쓰지 않는다. 세리프가 보이면 차가 말하는 중이라는 뜻이 된다.
- 위계는 크기와 굵기로만 만든다. 색으로 위계를 만들지 않는다.
- 줄은 한 문장 최대 2줄, 한 줄 한글 18자 안팎. `word-break: keep-all`로 어절 단위 줄바꿈.
- Pleos 가이드의 주 글자 높이 5mm, 보조 3mm 이상을 지킨다. 17인치 화면 기준 실제 px 34와 20에 해당한다 [가정: 화면 폭 약 376mm].
- 시스템 글꼴은 Asta Sans다. Pretendard를 싣지 못하면 정보 글자는 Asta Sans로 대체한다. 목소리 글꼴은 대체하지 않는다.

### 3.2 색 토큰

밤(기본):

| 토큰 | 값 | 쓰임 |
|---|---|---|
| room | `#09080B` | 바탕. 모든 단계 |
| hair | `rgba(255,255,255,.08)` | 헤어라인 |
| text-1 | `#EDEAF2` | 목소리, 값 (대비 약 16:1) |
| text-2 | `#A7A2B4` | 보조 문장, 조용한 버튼 (약 8:1) |
| text-3 | `#8A8599` | 라벨, 차 상태 (약 5.6:1) |
| text-rest | `#4A4656` | 머묾 중 "마치기"만. 일부러 낮은 대비 (접근성 예외, 6절) |
| light-sill | `#FFB15C` | 문턱, 들숨. 약 2800K |
| light-stay | `#FF9A3C` | 날숨, 머묾. 약 2300K |
| light-return | `#FFC489` | 돌아옴, 출발 준비. 약 3500K |
| accent | `#8E7BEA` | 브랜드 보라. 포커스 링과 설정 화면에만. 문턱선과 실내광에는 절대 쓰지 않는다 |

낮:

| 토큰 | 값 | 달라지는 점 |
|---|---|---|
| room | `#121016` | 한 단 올린 어두운 바탕. 낮에도 흰 바탕은 쓰지 않는다 |
| text-1 / 2 / 3 | `#F6F3FA` / `#C2BDCE` / `#A29DB1` | 햇빛 반사에 대비해 한 단씩 밝게 |
| 문턱선 | 같은 색, 두께 2배(실제 8px), 번짐 없음 | 햇빛 아래 번짐은 안 보인다. 선만 또렷이 |
| text-rest | `#6E6980` | 머묾 중 "마치기" |

규칙:
- 한 화면에 빛 색은 하나. 문턱선 색과 실내 앰비언트 색은 항상 같은 계열이다.
- 흰 면은 어느 단계에도 없다. 끝 화면도 검은 바탕이다.
- 빨강, 초록 같은 상태색을 쓰지 않는다. 실패는 문장으로 말한다.

### 3.3 빛의 동작 (화면과 실내가 함께)

실내광 값은 조명 통합 설계 v2를 따른다. 화면의 문턱선은 그 값을 그대로 비춘다.

| 단계 | 실내 앰비언트 (밤 / 낮) | 문턱선 길이 | 문턱선 밝기 |
|---|---|---|---|
| 준비 | 사용자 설정 그대로 | 패널 폭의 74% | 32%, 무채색 |
| 문턱 | `#FFB15C` 20% / 25%, 8초 | 100% → 62% (8초) | 95% |
| 숨 | 들숨 `#FFB15C` 20%, 날숨 `#FF9A3C` 15% / 낮 20% 고정 | 46% | 들숨 90%, 날숨 60% |
| 머묾 | `#FF9A3C` 15% / 20%, 변화 0 | 26% | 42%, 정지 |
| 돌아옴 | `#FFC489` 30%, 25초. 사용자 설정보다 밝게 끝내지 않는다 | 26% → 78% (25초) | 90% |
| 출발 준비 | 닫을 때 저장값으로 | 100% | 70% |

- 문턱선은 중심에서 좌우로 대칭으로 줄고 늘어난다. 문이 닫히고 열리는 방향이다.
- 빛은 선 아래로만 번진다. 선 위는 문이라 어둡다.
- 깜빡이는 촛불, 십자 모양, 색 순환은 쓰지 않는다.

### 3.4 움직임

| 무엇 | 시간 | 곡선 | 비고 |
|---|---|---|---|
| 문구 등장 | 600ms, 위로 4px(실제 8px) | ease-out | 한 번만 |
| 문구 퇴장 | 400ms | ease-in | 등장보다 빠르게 |
| 문턱선 좁아짐 | 8,000ms | 선형 | 앰비언트 페이드와 같은 시계 |
| 숨 원 | 들숨 4,000ms, 날숨 6,000ms | ease-in-out | 원 지름 400 ↔ 600 실제 px |
| 머묾 진입 | 화면 전환 없음 | | 마지막 날숨이 그대로 머묾이 된다. 점은 16초 뒤 800ms로 사라진다 |
| 문턱선 넓어짐 | 25,000ms | 선형 | 내릴 때보다 길게 |
| 문 열림, 기어 이탈 | 0~1,500ms | | 안전이 의례보다 먼저. 페이드 없이 물러난다 |
| 터치 응답 | 250ms 안에 눌림 표시 | | Pleos 가이드 |

- 한 화면에서 동시에 움직이는 것은 하나뿐이다.
- `prefers-reduced-motion` 또는 시스템 모션 줄이기에서는 문턱선과 원이 중간 크기로 멈추고 문구만 바뀐다.
- 주행 상태에서는 어떤 움직임도 없다. 앱 화면 자체가 물러난다.

## 4. 차량 화면 레이아웃

기준 캔버스 2560x1440. 시안은 1280x720 CSS에 2배 배율로 그렸다. 상단 시스템 띠 높이 88px은 [가정]이다.

### 4.1 전체 화면

```
┌──────────────────────────────────────────────┐
│ P                                      21:40 │  시스템 띠 (가정)
│                                              │
│                                              │
│          문을 닫고, 숨을 한 번 고를게요.     │  목소리: 가운데, 문턱선 위 136px
│        ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━        │  문턱선: 높이의 70% 지점, 고정
│                                              │
│ 문 잠김  창문 닫힘  빛 낮추는 중    [마치기] │  바닥 줄: 차 상태(왼쪽), 마치기(오른쪽)
└──────────────────────────────────────────────┘
```

- **목소리는 가운데, 결정은 운전석 쪽.** 의례 화면(문턱, 숨, 머묾, 돌아옴)은 가운데 정렬이고 누를 것이 거의 없다. 결정 화면(도착 제안, 출발 준비, 돌아왔을 때의 이어서 머물기)은 왼쪽 정렬이고 버튼이 운전석에서 가까운 왼쪽 아래에 있다 [가정: 좌핸들].
- 문턱선은 모든 화면에서 높이 70% 지점. 화면이 바뀌어도 눈이 돌아갈 자리가 같다.
- 바닥 줄 왼쪽에는 차가 지금 하는 일을 정보 글자로 적는다. 차가 먼저 읽고 "확인했어요"를 보여 주는 자리다(D7). 값은 최대 4개, 문장이 아니라 낱말 쌍.
- 바깥 여백 96px, 버튼 사이 32px.

### 4.2 반쪽 화면 (1280x1440)

```
┌──────────────────────┬──────────────────────┐
│ 잠시 머물다 갈까요   │                      │
│ 기도  15분           │      다른 앱         │
│ ━━━━━━━━━━━━━━━      │                      │
│ [머물기] [오늘은…]   │                      │
└──────────────────────┴──────────────────────┘
```

- 도착 제안은 항상 반쪽으로 뜬다. 보고 있던 화면을 다 덮지 않는다. 덮으면 요구가 된다.
- [머물기]를 누르면 전체 화면으로 넓어진다. 사용자가 반쪽을 유지하도록 설정했거나 옆 앱을 다시 열면 반쪽 레이아웃을 쓴다.
- 반쪽에서는 바닥 줄의 차 상태를 2개까지만 보이고, 목소리는 2줄로 접는다. 문턱선 높이는 같다.
- 옆 앱의 밝기는 우리가 못 바꾼다. 머묾에 들어갈 때 옆 앱이 밝으면 "화면을 넓힐까요"를 묻지 않는다. 선택은 사용자 것이다 [확인 필요: 앱이 스스로 전체 화면을 요청할 수 있는지].

### 4.3 터치

- 최소 터치 영역 76dp [가정: 팀 값, 근거 확인 중]. 시안의 버튼은 높이 184px(주 버튼), 176px(마치기)로 그렸다.
- 한 화면에 버튼은 최대 2개. 의례 화면에는 "마치기" 하나.
- 머묾 중에는 화면 어디를 두드려도 같은 일이 일어난다(화면이 낮은 밝기로 깨어남). 눈을 감았던 손이 버튼을 찾지 않게 한다.
- 길게 누르기, 쓸어 넘기기, 두 손가락 동작은 쓰지 않는다. 한 손, 한 번 누르기만.

## 5. 소리와 목소리

- **목소리:** 낮고 느린 한국어 TTS. 탭 뒤 선행 묵음 0.3초. 문장은 한 번만 말하고 반복하지 않는다. 음량은 앱 기준 대비 -12~-14dB.
- **짝 신호:** 시작과 끝은 같은 소리, 같은 횟수(기도 팩은 작은 종 한 번). 같은 소리면 "닫혔다", 다른 소리면 "끊겼다"가 된다.
- **침묵이 기본.** 제안은 소리가 없다. 머묾은 무음. "끝났어요"는 화면에만 쓰고 말하지 않는다. 종이 이미 말했다.
- 숨 안내 말은 첫 한 번만. 그 뒤는 원과 빛만.
- 사용자가 몸을 움직이는 동안에는 말하지 않는다. 마지막 움직임 뒤 4초 조용할 때 말한다.
- 효과음(버튼 딸깍, 완료 팡파르) 없음. 터치 확인은 화면의 눌림 표시로 한다 [확인 필요: 시스템 햅틱].
- 음원은 자체 녹음. 찬송, 반주, 배경 음악은 첫 판에 없다.

## 6. 문구 규칙

1. **"~하세요"가 아니라 "~할게요".** 차가 대신 해 주는 말이다. 명령하지 않는다.
2. **가르치지 않는다.** 기도하는 법, 묵상의 효과, 격려를 말하지 않는다. 말씀은 개역한글 한 구절을 머묾 시작에 한 번만 낭독하고 비워 둔다.
3. **한 화면 한 문장.** 목소리 문장은 20자 안팎, 쉼표는 하나까지. 쉼표는 낭독의 쉼이다.
4. **사실만 말한다.** "좌석과 공조를 원래대로 돌렸어요."처럼 차가 한 일을 그대로 적는다. 감탄, 칭찬, 위로를 넣지 않는다. 1분 만에 마쳐도 "괜찮아요"라고 하지 않는다.
5. **버튼은 사용자의 말로.** [머물기], [오늘은 그냥 갈게요], [마치기], [이어서 머물기], [조금 더 머물기]. 같은 동작은 끝까지 같은 이름. 끝 화면에는 닫기 버튼이 없다. 문을 열거나 기어를 옮기면 스스로 닫힌다.
6. **종교 낱말은 화면 밖으로.** 화면은 창밖에서 보인다. "기도 중", "아멘", "주님"을 화면에 쓰지 않는다. 제안 카드의 "기도 15분"은 사용자가 고른 의향 이름이라 예외이고, 세션이 시작되면 사라진다.
7. **실패는 방향으로.** "원래대로 돌렸어요.", "등받이를 운전 자세로 돌릴까요?"처럼 지금 상태와 다음 할 일을 말한다. 사과하지 않는다.
8. 문장부호: 마침표를 찍는다. 느낌표, 말줄임표, 줄표, 이모지는 쓰지 않는다.

정본 문구 목록은 화면 기능 명세 3절에 있다.

## 7. 접근성

- **대비:** 모든 글자 4.5:1 이상. 예외는 머묾 중 "마치기"(`#4A4656`, 약 2.2:1) 하나다. 보완: 화면 어디든 한 번 두드리면 5초간 text-2 밝기로 올라온다. 설정에서 "마치기를 항상 또렷이"를 켤 수 있다.
- **색에만 기대지 않는다.** 단계는 색과 함께 문턱선 길이, 문구, 소리로 겹쳐 알린다. 색각 이상이 있어도 길이로 읽힌다.
- **소리 없이도, 화면 없이도 끝까지 된다.** 청각 장애: 모든 음성 문장이 화면에 같은 글자로 나온다. 종은 문턱선의 한 번 밝아짐으로 대신한다. 시각 장애와 눈 감은 사용자: 시작부터 끝까지 음성과 종만으로 진행된다.
- **글자 크기:** 시스템 큰 글자 설정을 따른다. 목소리는 최대 2줄을 지키도록 1.3배까지만 커지고 그 이상은 줄을 나눈다.
- **모션 줄이기:** 3.4절.
- **한 손 조작, 큰 터치, 버튼 2개 이하:** 4.3절.
- **인지 부담:** 고르는 화면이 없다. 의향과 길이는 지난번 값을 쓴다. 바꾸는 일은 주차 중 설정 화면에서만 한다.

## 8. 화면에 절대 나오지 않는 것

- 남은 시간 숫자, 진행 막대, 카운트다운 (복귀 시각을 정한 사람이 화면을 두드렸을 때의 시계는 예외)
- 연속 일수, 배지, 점수, 통계, "오늘의 기록"
- "기도 중"이라는 표시와 종교 상징 그림. 십자, 촛불, 손 모은 그림, 성화
- 결제, 구독 권유, 추천 콘텐츠, 광고 (세션 안과 끝 화면 모두)
- 마침 확률, 모델 수치, "분석 중" 같은 기술의 흔적
- 사진, 영상, 일러스트, 캐릭터, 3D 차량 모형
- 보라색 빛, 흰 면, 그라데이션 배경, 유리 효과, 네온
- 공유 버튼, 다른 사람의 사용 현황
- 팝업 위의 팝업, 토스트 여러 개, 탭 바, 목록

## 9. 스스로 점검한 것과 남은 것

- 시안 10장과 콘택트 시트를 렌더해 눈으로 확인했다. 글꼴 로드, 휴대폰 화면 폭, 작은 글자 크기를 한 번씩 고쳤다.
- [확인 필요] Pleos 상태 바와 GNB 치수, 반쪽 창의 실제 폭, 버튼 최소 치수, 앱의 전체 화면 요청 가능 여부, 화면 밝기 제어 가능 여부.
- [가정] 실제 px 환산(17인치 폭), 76dp, 좌핸들 기준 버튼 위치.
- 낮 토큰은 값만 정했고 시안은 밤만 그렸다.
- 실차에서 문턱선 밝기가 앰비언트보다 튀는지는 조명 v2의 실험 B(화면 빛 측정)와 함께 본다.

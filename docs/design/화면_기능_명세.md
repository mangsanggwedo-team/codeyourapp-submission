작성 날짜: 2026-11-15 / Prompt-Ref: P144 / 상태: 초안
정본 관계: 문구와 시각은 `codeyourapp-submission/docs/journey/여정_초정밀.md`, 빛은 `D14_조명/02_조명_통합설계_v2.md`, 시각 언어는 `2026-11-15_룸19_디자인_컨셉.md`. 서로 다르면 그 문서들이 이긴다. 끝 화면과 멈춤은 하네스 2관문(`60_submission/harness/docs/08_feature-spec.md` F-10, F-21)에 맞춰 고쳤다: 닫기 버튼 없음, 돌아왔을 때 버튼 하나. 말씀과 기도문 화면은 같은 문서 F-23~F-25가 정본이고 시안은 아직 없다.

## 0. 공통

**화면 뼈대:** 검은 바탕(`#09080B`) + 문턱선(높이 70% 지점) + 목소리 한 줄 + 바닥 줄. 한 화면에 버튼 2개 이하.

**공통 컴포넌트**

| 이름 | 모양 | 크기 | 비고 |
|---|---|---|---|
| 문턱선 | 2px(실제 4px) 선 + 아래로 번지는 빛 | 길이·색·밝기는 단계별 | 누를 수 없음. 장식이자 단계 표시 |
| 목소리 | Noto Serif KR 400 | 112~152px | TTS와 같은 글자. 최대 2줄 |
| 주 버튼 | 헤어라인 테두리 + 옅은 면, Pretendard 600 48px | 높이 184, 최소 폭 440 | 눌림 250ms 안에 표시 |
| 조용한 버튼 | 테두리만, text-2 | 높이 184 | 거절, 보조 |
| 마치기 | 테두리만, text-2 42px | 176 x 352 | 의례 화면 오른쪽 아래 고정 |
| 차 상태 줄 | 낱말 쌍(라벨 text-3, 값 text-2) 44px | 최대 4쌍 | 차가 지금 하는 일. 누를 수 없음 |
| 점 셋 | 지름 18 원 3개 | | 머묾의 깊이. 숫자를 대신한다 |

**어느 화면에서나 같은 규칙 (안전)**

| 사건 | 화면 | 차 |
|---|---|---|
| 기어 P 이탈(D, R, N), 기어 신호 끊김 | 즉시 "원래대로 돌렸어요." 버튼 없음. 차가 움직이면 화면 비움 | 페이드 없이 복원: 빛 저장값 0ms, 풍량·열선 저장값, 소리 0. 등받이는 거부되면 건너뛰고 다음 P에서 묻는다 |
| 운전석 문 열림 | 비움 | 빛 1.5초 안에 올림. 좌석은 절대 움직이지 않는다. 모델 시계 멈춤 |
| 문 닫고 다시 앉음(120초 안) | [이어서 머물기] 하나만 20초. 누르지 않으면 말없이 되돌리고 닫는다 | 누르면 머묾 빛으로 8초, 멈춘 자리에서 잇는다 |
| 120초 넘게 비움 | 세션 끝, 카드 없음 | 저장값 복원(좌석은 문 닫힌 뒤) |
| 전화 등 오디오 포커스 잃음 | "잠시 멈춰 둘게요." | 빛 22%로 3초. 모델 시계 멈춤 [확인 필요: 포커스 신호] |
| 통화 끝 | "이어서 머물러요." 숨 안내는 다시 하지 않는다 | 빛 머묾 값으로 8초 |
| 통화 3분 초과 | [이어서 머물기] 하나만 20초 | 누르지 않으면 말없이 복원 |
| 앱 강제 종료, 재부팅 | 다음 시작 때 조용히 복원 후 지움 | 디스크 저장값으로 복원 |
| [마치기] 누름 (어느 단계든) | 돌아옴 화면으로 | 돌아옴 순서 그대로. 60초 미만 세션은 문장 없이 닫고 개인화에서 뺀다 |

## 1. Pleos판

### S0. 침묵 (화면 없음)

- **목적:** 주행 중과 주차 직후 6초 동안 아무것도 하지 않는다.
- **진입:** 앱 설치 상태에서 항상. **종료:** 진입 허용 조건이 6~7초 유지되면 S1.
- **문구·컴포넌트:** 없음.
- **차:** get 준비만. set 없음.
- **엣지:** 기어·차속 신호를 못 받으면 주행으로 본다. 착좌 신호가 없으면 제안하지 않는다. 조수석 착좌가 있으면 제안하지 않는다.

### S1. 도착 제안 (준비) · 시안 `01_도착_제안`

- **목적:** 묻는다. 요구하지 않는다.
- **진입:** P + 차속 0 + 운전석 착좌 + 운전석 문 닫힘이 6~7초 유지 [가정]. **종료:** [머물기] → S2. [오늘은 그냥 갈게요] 또는 10초 무응답 → 조용히 접힘. 자동 시작 없음.
- **레이아웃:** 반쪽(운전석 쪽). 보던 앱은 옆에 그대로.
- **문구:**
  - 목소리: `잠시 머물다 갈까요`
  - 보조: `기도  15분` (지난번 의향과 길이. 복귀 시각을 정한 사람은 `조용히 머물기  12시 28분까지`)
  - 버튼: `머물기` / `오늘은 그냥 갈게요`
- **컴포넌트:** 목소리, 보조 줄, 문턱선(무채색, 밝기 32%), 주 버튼, 조용한 버튼.
- **터치:** 두 버튼 높이 184, 간격 32. 버튼 밖을 눌러도 닫히지 않는다(실수로 거절되지 않게).
- **차:** 아무것도 바꾸지 않는다. 소리 없음.
- **엣지:**
  - 뒷좌석 착좌(아이): 제안은 뜨되 시작하면 TTS를 끄고 화면 글자만, 종은 -24dB.
  - 내연기관 공회전 + 외기 5~25℃: 보조 줄 아래 한 번 `2분 넘게 공회전하면 과태료 지역일 수 있어요. 시동을 끄고 머물까요?`
  - 12V·SOC 낮음: 보조 줄 `오늘은 빛과 소리만 바꿀게요.`
  - 충전 중: 보조 줄을 `충전이 끝나는 21시 58분까지`로 [가정].
  - 밤 22시 이후: 화면 변화 없음(빛 상한만 20%).
  - 연속 사용 며칠째든 문구는 같다.

### S2. 문턱 · 시안 `02_문턱`

- **목적:** 문이 닫혔다는 것을 빛과 한 문장으로 알린다. 차가 대신 한다.
- **진입:** S1 [머물기]. **종료:** 8초 뒤 종 한 번과 함께 S3.
- **문구:**
  - 목소리(화면과 TTS 같음): `문을 닫고, 숨을 한 번 고를게요.`
  - 차 상태 줄: `문 잠김` `창문 닫힘` `빛 낮추는 중` `바람 2`
  - 버튼: `마치기`
- **컴포넌트:** 목소리(가운데), 문턱선(`#FFB15C`, 100% → 62%, 8초), 차 상태 줄, 마치기.
- **터치:** 마치기 176 x 352, 오른쪽 아래.
- **차 (순서):** ① 공조·좌석·조명·창문·문 값을 읽어 디스크에 기록 ② 앰비언트 → 20% `#FFB15C` 8초(낮 25%) ③ +2초 풍량 3→2, 열선 0→1(겨울) ④ +3초 등받이를 조금 뒤로(0.55→0.45) ⑤ +5초 풍량 →1 ⑥ +8초 종 한 번. 이미 잠긴 문은 다시 잠그지 않는다.
- **엣지:**
  - 읽기 실패한 항목은 바꾸지 않고 차 상태 줄에서 뺀다.
  - 등받이 거부(50001): 건너뛰고 문구 그대로.
  - 창문이 열려 있음: 닫지 않는다. 차 상태 줄에 `창문 열림`으로 사실만 적는다 [가정: 창문 set은 끼임 위험으로 첫 판 제외].
  - 비: 차 상태 줄 변화 없음, 배경음 생략.
  - 한낮: 빛을 25%까지만. 문턱선은 번짐 없이 선만.
  - 반쪽: 목소리 2줄, 차 상태 2쌍(`문 잠김` `빛 낮추는 중`).

### S3. 숨 · 시안 `03_숨`

- **목적:** 날숨이 들숨보다 길어지게 한다. 채점하지 않는다.
- **진입:** S2의 종. **종료:** 숨 6번(약 60초) 뒤 자동으로 S4. 화면 전환 없이 원만 사라진다.
- **문구:**
  - 원 안(첫 한 번만, TTS 같음): `들이쉬고` → `내쉬고`
  - 두 번째 숨부터: 글자 없음, 원만
  - 버튼: `마치기`
- **컴포넌트:** 숨 원(선 하나, 지름 400 ↔ 600, 들숨 4초 날숨 6초, 문턱선 위에 얹힘), 문턱선(46%), 마치기.
- **차:** 앰비언트 들숨 20% `#FFB15C`, 날숨 15% `#FF9A3C`. 한낮에는 20% 고정. 마지막 날숨 값이 그대로 머묾 빛이 된다.
- **엣지:**
  - 빛 제어 지연이 크면 15%에 고정하고 원만 움직인다.
  - 숨 세기, 횟수 표시 없음. 사용자가 원을 따라가지 않아도 넘어간다.
  - 모션 줄이기: 원은 중간 크기로 멈추고 `들이쉬고` `내쉬고` 글자만 4초, 6초로 바뀐다.
  - 통화 뒤 복귀 때는 이 화면을 다시 보여 주지 않는다.

### S4. 머묾 · 시안 `04_머묾`, `07_머묾_반쪽`

- **목적:** 비켜 준다. 화면이 없는 것처럼.
- **진입:** S3 끝. **종료:** 마침 모델이 마침 단계에 들어가고 마지막 움직임 뒤 4초 조용하면 S5. 또는 [마치기]. 상한 30분.
- **문구:**
  - 진입 직후 TTS 한 번(기도 팩): 마 6:6 개역한글. 화면에는 글자 없이 점 `● ○ ○`
  - 낭독 실패 시에만 화면에 같은 구절을 목소리 글꼴 2~3줄로
  - 16초 뒤: 점도 사라지고 `마치기`만 아주 낮은 밝기(`#4A4656`)
- **컴포넌트:** 문턱선(`#FF9A3C`, 26%, 밝기 42%, 정지), 점 셋, 마치기(낮은 밝기).
- **터치:**
  - 화면 어디든 한 번: 5초간 깨어남. 점 셋이 지금 깊이를 보여 준다(`● ● ○`). 마치기가 text-2로 올라온다. 시계는 없다. 복귀 시각을 정한 사람에게만 `12:27`.
  - 깨어난 5초 안에 마치기: S5.
  - 터치는 마침 신호로 30초에 한 번만 센다.
- **차:** 빛 변화 0. 창문 0%, 잠금 유지. 기어·차속·문·착좌를 1초마다 확인. 내기였다면 10분마다 외기 확인. 마침 확률 0.5부터 빛 +2%/분.
- **엣지:**
  - 사용자가 공조를 손으로 바꿈: 화면 변화 없음. 신호로만 쓴다.
  - 창문을 손으로 내림(경비원 등): 소리 즉시 물림, 빛 30%로 3초. 끝내자고 하지 않는다.
  - 30분 상한: S5로 가되 마침 문장 뒤에 `출발하기 전 2분만 더 앉아 있어요.`
  - 15분 넘게 신호 없음: 묻지 않는다. 모델이 넘기면 평소대로 마친다.
  - 방향지시등: 사실상 출발 준비. S5로.
  - 반쪽: 문턱선 36%, 마치기만. 옆 앱 밝기는 건드리지 못한다.
  - 뒷좌석 아이가 깸: 사용자의 화면 터치로 처리. 마이크는 듣지 않는다.

### S5. 돌아옴 · 시안 `05_돌아옴`

- **목적:** 알아챘다는 것을 한 문장으로 말하고, 먼저 보이고 다음에 몸, 마지막에 귀 순서로 되돌린다.
- **진입:** 마침 단계 + 4초 조용함, 또는 [마치기]. **종료:** 복원이 끝나면 S6(약 45~90초).
- **문구:**
  - 목소리(TTS 한 번): `이제 천천히 돌아올게요.`
  - 좌석 이동 중 목소리 자리: `좌석을 원래대로 돌리고 있어요.` (TTS 없음)
  - 차 상태 줄: `빛 올리는 중` `등받이 곧 운전 자세로` `바람 1`
- **컴포넌트:** 목소리, 문턱선(`#FFC489`, 26% → 78%, 25초), 차 상태 줄. **버튼 없음.** 이미 끝나는 중이라 마치기가 필요 없다.
- **차 (순서):** ① 문장 5초 뒤 종 한 번(시작과 같은 소리)과 함께 앰비언트 → 30% `#FFC489` 25초. 사용자 저장값이 30%보다 낮으면 저장값까지만 ② 등받이 저장값으로 ③ 풍량 1→2→3, 30초에 걸쳐 ④ 온도는 바뀐 경우에만 마지막에.
- **엣지:**
  - 사용자가 다시 눕거나 눈을 감아 확률이 내려가면: 문장을 말하기 전이면 조용히 되돌린다. 말한 뒤에는 끝까지 간다.
  - 좌석 이동 중 문 열림: 즉시 정지.
  - 등받이 거부: 차 상태 줄에서 빼고 S6에서 묻는다.
  - 뒷좌석 착좌: TTS 없이 글자만.

### S6. 출발 준비 · 시안 `06_출발_준비`

- **목적:** 약속을 지켰다는 것을 보여 주고 놓아준다.
- **진입:** 복원 끝. **종료:** 문 열림, 기어 이동, 시동 끔, 90초 가운데 먼저 오는 것. 닫기 버튼은 없다. 이때 빛을 저장값으로 되돌린다.
- **문구:**
  - 목소리(화면만, TTS 없음): `끝났어요.`
  - 보조: `좌석과 공조를 원래대로 돌렸어요.` (복귀 시각을 정한 사람은 `12시 28분이에요.`)
  - 되돌린 값: `등받이 운전 자세` `바람 3` `온도 22℃` `빛 원래 밝기`
  - 때에 맞는 한 줄(많아야 하나): `천천히 올라가세요.` `12시 38분이에요.` `출발해도 좋아요.`
  - 버튼: 없음. 끝이 일렀을 법할 때만 `조금 더 머물기` 하나 [시안 `06_출발_준비`에는 아직 닫기 버튼이 그려져 있다]
- **컴포넌트:** 목소리 152px(왼쪽), 보조 줄, 되돌린 값 목록(오른쪽, 헤어라인 4줄, 실제로 바꾼 것만), 문턱선(끝에서 끝까지).
- **터치:** 평소에는 누를 것이 없다. `조금 더 머물기`가 보일 때만 184 x 440, 왼쪽 아래. 화면을 길게 눌러도 같은 일이 된다.
- **차:** 닫을 때 앰비언트 저장값. 열선은 시동을 끌 때 0.
- **엣지:**
  - 못 되돌린 값이 있으면 그 줄만 `등받이 다음 주차 때 돌릴게요`로 적는다. 보조 문장은 `공조를 원래대로 돌렸어요.`처럼 사실에 맞게 줄인다.
  - 복원 전에 시동이 꺼짐: 저장값을 남겨 다음 시동 때 적용.
  - 30분 상한으로 끝났으면 보조 줄 `출발하기 전 2분만 더 앉아 있어요.`
  - 이 화면에 기록, 통계, 구독 권유, 다음 추천은 없다.

### S7. 다음 P에서의 복원 확인

- **진입:** 기어 이탈로 등받이를 못 돌린 채 이동한 뒤 다시 P. **문구:** `등받이를 운전 자세로 돌릴까요?` [돌리기] [그대로]. **차:** [돌리기]일 때만 등받이 저장값. 10초 무응답이면 접히고 저장값은 지운다 [가정].

### S8. 설정 (주차 중, 앱을 직접 열었을 때만)

- **목적:** 세션 밖에서만 고른다. 세션 안에는 고르는 화면이 없다.
- **항목:** 의향(기도 / 조용히 머물기 [확장]), 길이 또는 복귀 시각, 머묾 빛 한 단 어둡게·밝게, 말씀 낭독 켬·끔, 마치기를 항상 또렷이, 목소리 끔(글자만), 제안 카드 끔, 기기 안 기록 지우기.
- 정보 글꼴만 쓴다. 보라 accent는 여기 포커스와 선택 표시에만 쓴다. 시안은 다음 판.

## 2. 휴대폰 간이판 (일반 차용)

**전제:** 차량 제어 없음. 휴대폰 센서, 차 블루투스 연결, 운전 종료 감지로 동작한다. 마이크·서버 없음. 목적은 Pleos 탑재 전에 사용자와 시장성을 먼저 확인하는 것. 390x844 기준, 치수는 CSS px.

**차량판과 다른 점**

| 항목 | Pleos판 | 휴대폰 간이판 |
|---|---|---|
| 문턱 | 차가 빛·바람·등받이를 바꾼다 | 휴대폰 화면만 어두워진다. 문은 사용자가 닫는다 |
| 빛 | 앰비언트 + 화면 문턱선 | 화면 문턱선뿐. 화면 밝기를 낮출 수 있으면 낮춘다 [확인 필요: OS 권한] |
| 마침 신호 | 등받이, 터치, 벨트, 방향지시등 등 | 화면 터치, 휴대폰을 집어 듦(가속도), 차 블루투스 끊김(시동 끔), 경과 시간 [가정] |
| 복원 | 좌석·공조·빛을 되돌린다 | 되돌릴 것이 없다. 화면 밝기와 방해 금지만 되돌린다 |
| 끝 문장 | 좌석과 공조를 원래대로 돌렸어요. | 이제 내려도 괜찮아요. |

### P1. 제안 · 시안 `p1_제안`

- **진입:** 차 블루투스 연결 상태에서 운전 종료 감지(이동 멈춤 약 10초) [가정]. 소리·진동 없는 알림 한 줄 `잠시 머물다 갈까요`. 알림을 눌러야 이 화면이 열린다. 자동으로 화면을 켜지 않는다.
- **종료:** [머물기] → P2. [오늘은 그냥 갈게요] 또는 알림 무시 → 30초 뒤 알림 스스로 사라짐.
- **문구:** `잠시 머물다 갈까요` / `기도  15분` / 버튼 `머물기` `오늘은 그냥 갈게요`
- **컴포넌트·터치:** 목소리 31px 가운데, 문턱선(무채색), 버튼 2개 세로 쌓기 높이 62, 폭 화면 폭에서 48 뺀 값, 엄지 닿는 아래쪽.
- **엣지:** 블루투스가 없는 차: 앱을 직접 열어 [머물기]. 걷는 중·대중교통으로 판단되면 제안하지 않는다. 아직 움직이는 중이면 열려도 `차가 멈춘 뒤에 열어 주세요.` 한 줄만.

### P2. 문턱과 숨 · 시안 `p2_숨`

- **진입:** P1 [머물기]. **종료:** 문턱 문장 8초 → 숨 6번 → P3.
- **문구:** 문턱 `차 문을 닫으셨다면, 숨을 한 번 고를게요.` (TTS 같음) → 원 안 `들이쉬고` `내쉬고` (첫 한 번만) / 버튼 `마치기`
- **컴포넌트·터치:** 숨 원(지름 150 ↔ 232), 문턱선 58%, 마치기 높이 56 오른쪽 아래.
- **휴대폰:** 방해 금지 켬(허용한 경우), 화면 꺼짐 방지, 밝기 낮춤. 소리는 휴대폰 스피커 또는 차 블루투스.
- **엣지:** 전화 수신: 일시정지, 통화 뒤 `이어서 머물러요.` 숨은 다시 하지 않는다. 블루투스 끊김(시동 끔): 계속한다. 시동을 끄고 머무는 사람이 많다.

### P3. 머묾

- **화면:** 차량판 S4와 같다. 거의 검은 화면, 문턱선 26%, 낮은 밝기 `마치기`. 말씀은 진입 때 한 번 낭독.
- **터치:** 한 번 두드리면 5초 깨어남. 휴대폰을 엎어 두면 화면을 끈다(근접 센서).
- **종료:** 마침 모델(휴대폰 신호) 또는 [마치기]. 상한 30분.
- **엣지:** 엎어 둔 상태에서 끝날 때: 종 한 번만. 화면은 집어 들 때 P4를 보여 준다. 차가 움직이기 시작하면(속도 감지) 즉시 무음 종료, 화면 비움.

### P4. 마침 · 시안 `p3_마침`

- **진입:** 마침 문장 `이제 천천히 돌아올게요.`(TTS 한 번)와 종 뒤. **종료:** 60초 뒤 스스로 닫힘. 휴대폰 간이판은 한 줄과 [닫기] 하나를 남긴다(차의 문과 기어 신호를 못 받기 때문이다).
- **문구:** `끝났어요.` / `이제 내려도 괜찮아요.` / 버튼 `닫기`
- **컴포넌트·터치:** 목소리 44px, 문턱선 끝에서 끝까지 `#FFC489`, 닫기 높이 62.
- **휴대폰:** 방해 금지와 밝기를 원래대로.
- **엣지:** 30분 상한: 보조 줄 `출발하기 전 2분만 더 앉아 있어요.` 기록·공유·구독 화면으로 이어지지 않는다. Pleos판 안내는 설정 맨 아래 한 줄로만 둔다.
